# A simple CLI programm that helps manage finances by:
-> tracking income, expenses, debts and savings
-> giving financial summary

## FEATURES
#### savetocsv.py
* Initializes a csv file(to keep record of transactions)
* Saves the transactions to the csv file

#### expense.py
* find expense transactions and record to the csv file

#### income.py
* find income transactions and record to the csv file

#### debtandsavings.py
* Keep record of debt owed and debt lent
* Keep record of savings

#### financialsummary.py
* give the summary for a specified period

#### main.py
* The execution file
