A simple CLI programm that helps manage finances by:
-> tracking income, expenses, debts and savings
-> giving financial summary

---FEATURES---
savetocsv.py
1. Initializes a csv file(to keep record of transactions)
2. Saves the transactions to the csv file

expense.py
1. find expense transactions and record to the csv file

income.py
1. find income transactions and record to the csv file

debtandsavings.py
1. Keep record of debt owed and debt lent
2. Keep record of savings

financialsummary.py
1. give the summary for a specified period

main.py
1. The execution file
